# ASmart MT5

Два индикатора для MetaTrader 5: разметка структуры рынка в стиле SMC/ICT и набор точек интереса со сигнальными свечами.

Это не советник. Индикаторы ничего не покупают и не продают. Сделку открываете вы, по правилам из этого руководства.

Автор: Evgeniy Acteck, makdak23@mail.ru.

Файлы:

- `ASmart SMC.mq5` — структура, сломы, ордер-блоки, имбалансы, дашборд.
- `ASmart Tools.mq5` — сигнальные свечи, сигнал входа, сессии, уровни ликвидности, поток ордеров.

Оба файла ставятся на один и тот же график. По отдельности система входа не собирается: блоки рисует SMC, свечи рисует Tools.

## Что вы видите на графике

| Метка | Что это простыми словами | Зачем в сделке |
|---|---|---|
| Точки структуры | Подтверждённые максимумы и минимумы | По ним видно, куда «ломается» рынок |
| BoS | Слом структуры по тренду: цена закрылась за прошлым экстремумом в сторону текущего движения | Подтверждение, что тренд жив |
| ChoCh | Слом против тренда: характер движения сменился | Ранний признак разворота |
| Sweeped BoS / Sweeped ChoCh | Фитиль зашёл за уровень, а закрытие осталось внутри | Ложный пробой, ликвидность сняли и вернули цену |
| IDM | Первый откат после нового структурного экстремума | Пока цену за этот откат не забрали, слом считается сырым |
| OB-EXT | Сильный ордер-блок: последняя противоположная свеча ноги, которая сломала уровень | Основная зона для входа полным рабочим риском |
| OB-IDM | Слабый ордер-блок на свече отката IDM | Зона есть, но риск в ней меньше |
| Previous OB-EXT | Предыдущий сильный блок | Контекст, не свежий вход сам по себе |
| SMT | Ложный блок: фитиль прошил зону, а закрытие вернулось | Ловушка. Как обычный блок для входа не используется |
| FVG | Дырка между тремя свечами, куда тени не зашли | Место, куда цена часто возвращается до продолжения |
| Live BoS / Live ChoCh / Live IDM | То же самое, но по ещё не закрытой свече, пунктиром | Предупреждение. Вход только после закрытия свечи |
| Панель SMC | Направление Long / Short / Flat на трёх старших таймфреймах | Фильтр: не лезьте против всех трёх строк сразу |
| Рамка Smart Point | Сигнальная свеча Tools | Триггер входа, но только у своего ордер-блока |

Цвета SMC по умолчанию: рост — бирюзовый, падение — кирпично-красный, блоки — тёмно-синие, имбаланс — оранжевый.

## Установка с нуля

1. Откройте MetaTrader 5.
2. Меню **Файл → Открыть каталог данных**.
3. Перейдите в `MQL5/Indicators`.
4. Скопируйте туда оба файла: `ASmart SMC.mq5` и `ASmart Tools.mq5`.
5. Откройте MetaEditor (клавиша F4 в терминале или иконка IDE).
6. В навигаторе MetaEditor откройте каждый файл и нажмите **Компилировать** (F7). Внизу должно быть «0 errors, 0 warnings». Рядом появятся файлы `.ex5`.
7. В терминале откройте окно **Навигатор**, щёлкните правой кнопкой по **Индикаторы** и выберите **Обновить**.
8. Откройте график нужного инструмента.
9. Дважды щёлкните **ASmart SMC**, затем так же **ASmart Tools**.
10. В окне настроек нажмите **ОК**. Лицензионного ключа нет и вводить ничего не нужно.

Если после компиляции индикаторов нет в навигаторе, ещё раз обновите список индикаторов. Если график пустой, сожмите его колёсиком мыши или перейдите на старший таймфрейм: блоки могли уйти далеко вверх или вниз после сильного движения.

Рекомендуемые таймфреймы самой системы:

- криптовалюта: 1 минута или 5 минут;
- форекс, акции, индексы: 5 минут или 15 минут.

Индикаторы считаются на любом символе, который есть в вашем терминале. Глубина истории по умолчанию — 2000 баров. Ноль в поле длины означает «вся доступная история»; на слабом компьютере график может начать тормозить.

## Настройка, с которой уже можно разбирать сделки

Заводские параметры SMC структуру показывают. Сигнальные свечи по умолчанию выключены, поэтому система входа из коробки не видна. Сделайте так.

### ASmart SMC — что оставить

Оставьте включённым:

- Draw structure: **for whole price history**
- Length in bars: **2000**
- IDM Mode: **ext_idm**
- Show current structure: **true**
- Show dashboard: **true**, положение **Bottom** и **Right**, Higher TFs: **Auto-select**
- Structure Points, IDM, BoS, ChoCh, Sweeped BoS, Sweeped ChoCh
- OB-IDM, OB-EXT, Previous OB-EXT, SMT
- Live IDM, Live BoS, Live ChoCh

Выключите на первое время, чтобы график не шумел:

- Show HTF structure
- Show inner structure
- Live secondary IDM
- Colour background by structure
- Show trend divider
- Show Premium/Discount Zones
- весь блок **Alerts | External Structure** (BoS, BoS sweep, ChoCh, ChoCh sweep, IDM, IDM sweep, OB-IDM, OB-EXT, Previous OB-EXT, SMT)

Внешние оповещения по умолчанию включены и будут всплывать на каждый подход цены к старому уровню. Для обучения это мешает.

### ASmart Tools — что включить

Уже включено и так и оставьте:

- **Show Smart Point** = true
- **Show entry signal** = true
- **Alert on candle close** = true

- Velocity Indicator = true, цвета DodgerBlue и DarkOrchid
- SMC Indicator = true, цвета LimeGreen и Crimson
- Box Border Width = 2
- Enable Filter LQD Sweep = false, пока учитесь видеть сами свечи. Позже можно включить: тогда свеча рисуется только если она сняла экстремум предыдущей свечи и закрылась обратно.

Остальное (FVG, SCOB, равные хаи, максимум прошлого дня, длинные тени, сессии, поток ордеров) для первой недели оставьте выключенным. Это контекст, не вход.

### Что означают режимы, если захотите их трогать

**IDM Mode**

- `ext_idm` — крупная структура. Меньше меток, меньше шума. Так и стоит по умолчанию.
- `int_idm` — более мелкая структура внутри последнего внешнего диапазона. Меток больше, ложных сломов тоже больше.

**Show HTF structure** рисует структуру выбранного старшего таймфрейма (по умолчанию H1) поверх текущего графика. Включайте, когда уже отличаете свой BoS от чужого: подписи пока одинаковые.

**Show inner structure** добавляет микроструктуру с приставкой `i-` в подписях.

**Дашборд.** Auto-select берёт три старших таймфрейма от текущего. На M5 это M15, H1 и H4. На M15 это H1, H4 и D1. На M1 это M5, M15 и H1. Ручной режим использует TF1, TF2 и TF3. Long — структура вверх, Short — вниз, Flat — направления ещё нет.

**Premium/Discount** делит последний структурный диапазон пополам. Выше середины цена «дорогая» (премиум, искать продажи). Ниже середины цена «дешёвая» (дисконт, искать покупки). Середина — равновесие. Пока зоны выключены, это правило держите в голове: не покупайте у самого верха диапазона и не продавайте у самого низа.

## Правила открытия сделки

Сигнальная свеча без ордер-блока входом не является. Ордер-блок без сигнальной свечи тоже не является входом.

Нужны одновременно три вещи:

1. На графике есть живой ордер-блок нужного направления: бычий для покупки, медвежий для продажи.
2. Цена пришла в этот блок (тест) или пробила его и вернулась к нему.
3. Появилась сигнальная свеча того же направления, что и блок. Свеча должна закрыться. Пунктир Live на незакрытой свече — это ещё не сигнал.

### Какие свечи какие

Tools рисует рамку на всю сигнальную свечу.

| Рамка | Модуль | Сила | Направление |
|---|---|---|---|
| Зелёная, LimeGreen | SMC | сильная | покупка |
| Голубая, DodgerBlue | Velocity | слабая | покупка |
| Красная, Crimson | SMC | сильная | продажа |
| Фиолетовая, DarkOrchid | Velocity | слабая | продажа |

Сильная свеча (SMC) — это свеча доминирования: тело не меньше половины среднего истинного диапазона за 14 баров, а закрытие находится в крайних 25% свечи в сторону движения.

Слабая свеча (Velocity) — импульс послабее: весь диапазон свечи не меньше этого среднего диапазона, тело занимает хотя бы 40% свечи, и при этом свеча не дотянула до условий сильной.

Если включён LQD Sweep, свеча дополнительно должна снять экстремум предыдущей свечи фитилём и закрыться обратно за него.

Пороги в исходном описании числом не заданы. В индикаторе приняты значения выше. Если рамок слишком много, включите LQD Sweep. Если рамок почти нет, оставьте фильтр выключенным.

### Какой объём риска брать

«100%» — это не весь депозит. Это ваш обычный риск на одну нормальную сделку. Если вы обычно рискуете 0,5% депозита, то 100% — это те же 0,5%, 50% — это 0,25%, 25% — это 0,125%.

Покупка:

| Свеча | Блок | Доля вашего обычного риска |
|---|---|---|
| Зелёная, сильная | OB-EXT | 100% |
| Зелёная, сильная | OB-IDM | 50% |
| Голубая, слабая | OB-EXT | 50% |
| Голубая, слабая | OB-IDM | 25% |

Продажа:

| Свеча | Блок | Доля вашего обычного риска |
|---|---|---|
| Красная, сильная | OB-EXT | 100% |
| Красная, сильная | OB-IDM | 50% |
| Фиолетовая, слабая | OB-EXT | 50% |
| Фиолетовая, слабая | OB-IDM | 25% |

OB-EXT — сильный блок. OB-IDM — слабый. Сильная свеча у сильного блока — единственный случай полного рабочего риска. SMT и Previous OB-EXT в эту таблицу не входят. Доли 75% в таблице нет: стрелка показывает только 100%, 50% или 25%.

Строка «красная свеча и OB-IDM» в исходном описании обрезана. 50% взяты по той же схеме, что и у зелёной свечи с OB-IDM.

### Куда ставить стоп

Выберите один вариант, тот, который ближе к логике конкретной свечи:

- стоп за границу ордер-блока, от которого появилась свеча: для покупки ниже нижней границы блока, для продажи выше верхней;
- стоп за сигнальную свечу, если она сама очень большая и блок из-за этого оказывается слишком далеко;
- стоп за ближайший максимум или минимум, который образовался уже после теста или пробоя блока.

Не ставьте стоп «на глаз внутри блока». Если цена вернулась внутрь зоны и закрылась за вашим стопом, сценарий для этой попытки отменён.

### Куда ставить тейк

Первый тейк (TP1) ставится так, чтобы прибыль равнялась риску: расстояние от входа до тейка равно расстоянию от входа до стопа. Это отношение 1 к 1.

Дальний тейк (TP2) — следующий свинг структуры за TP1. Если такого свинга нет в пределах пяти рисков, TP2 ставится на 2 к 1. В руководстве описан только TP1. TP2 добавлен как дальний ориентир и не заменяет выход 1 к 1.

Пример. Вход 1.1000, стоп 1.0980, риск 20 пунктов. Тейк для покупки — 1.1020. Для продажи при входе 1.1000 и стопе 1.1020 тейк — 1.0980.

Пока сделка не закрыта, тейк не отодвигайте «ещё немного». Система из руководства рассчитана на 1 к 1, а не на удержание до следующего дня.

### Пошаговый сценарий покупки

1. На дашборде старшие таймфреймы не все Short. Идеально, если хотя бы один старший Long или Flat, а текущая структура не в явном медвежьем ChoCh против вас.
2. На графике есть бычий OB-EXT или бычий OB-IDM. Цена к нему ещё не приходила после формирования, либо только что пришла.
3. Дождитесь теста зоны или пробоя с возвратом.
4. Дождитесь закрытия зелёной или голубой сигнальной свечи в эту сторону.
5. Сразу после закрытия этой свечи ASmart Tools ставит стрелку BUY или SELL, подпись с долей риска, линии SL, TP1 и TP2 и окно Alert. Сделку открываете вы сами. Долю риска возьмите из подписи.
6. Стоп поставьте по одному из трёх правил выше.
7. Тейк поставьте на ту же дистанцию, что и стоп.
8. Дальше сделку не переставляйте, кроме случая ниже.

### Пошаговый сценарий продажи

То же самое зеркально: медвежий блок, красная или фиолетовая свеча, стоп выше зоны, тейк на дистанции стопа вниз. Не продавайте только потому, что свеча красная в пустом месте.

### Если выбило по стопу

Можно войти ещё один раз, и только один. Условия повторного входа:

- тот же ордер-блок или та же зона после его пробоя;
- цена сняла ликвидность (фитиль за локальный экстремум) и снова появилась сигнальная свеча того же направления;
- доля риска заново берётся по таблице, а не «отыгрывается» увеличением лота.

Третьей попытки в этой зоне нет. Если второй стоп тоже случился, сценарий закрыт. Ждите новый блок.

## Как вести сделку после входа

Ведение здесь короткое, потому что выход задан заранее.

1. Стоп и тейк выставляются в момент входа, не «потом, когда дойдёт».
2. Пока цена идёт к тейку, стоп не подтягивается. Трейлинг в правилах системы не описан, и индикатор его не делает.
3. Не закрывайте половину позиции на половине пути. Расчёт 1 к 1 ломается, если забирать прибыль раньше.
4. Не усредняйтесь. Добавлять объём к убыточной позиции нельзя. Единственное исключение — один новый вход после стопа, и то отдельной сделкой с её собственным стопом, а не доливка к старой.
5. Если до тейка вышла противоположная сигнальная свеча у противоположного блока, это уже новый сценарий, а не повод двигать стоп текущей сделки. Текущую ведите до стопа или тейка.
6. Не переносите стоп в плюс «на всякий случай» в первую же минуту. Для этой системы стоп защищает сценарий блока, а не комфорт.
7. В новостях и на выходе крупных сессий спред расширяется. Если стоп стоит в нескольких пунктах и его может снять спред, сделку лучше не открывать.

Дашборд во время сделки смотрите как фон, а не как команду закрыться. Смена надписи Long на Short на одной строке сама по себе сделку не отменяет.

## Как читать структуру, чтобы не путаться

Рынок вверх: максимумы и минимумы повышаются. Слом вверх через прошлый максимум с закрытием — бычий BoS.

Рынок вниз: максимумы и минимумы понижаются. Слом вниз через прошлый минимум с закрытием — медвежий BoS.

ChoCh — первое закрытие против этой последовательности. После ChoCh старый тренд под вопросом. Новый вход по старому направлению в этот момент не берётся, пока не появится блок уже нового направления и своя свеча.

IDM — первый откат после такого слома. Пока цену за этот откат не вынесли фитилём, слом ещё не «забран». На пунктире Live IDM не входите.

Свип — фитиль за экстремумом и закрытие обратно. Это не BoS. Часто после свипа как раз и появляется блок, но входите всё равно только по свече у блока, а не по самому фитилю.

## Дополнительные слои Tools, когда база уже понятна

Включайте по одному слою и смотрите неделю, прежде чем добавить следующий.

**Fair Value Gap.** Имбаланс из трёх свечей. Бычий: минимум более новой свечи выше максимума более старой. Медвежий — наоборот. «Extend FVG to the right» продлевает незакрытые зоны вправо, не больше числа из «Amount of extended FVGs to show» (по умолчанию 10). «Update FVG body when swept» сужает зону, если в неё зашёл фитиль, но дырка ещё не закрыта полностью. Старший имбаланс включается отдельно: Show MTF FVGs и таймфрейм FVGs MTF.

**SCOB.** Ордер-блок из одной свечи: она сняла экстремум предыдущей и закрылась обратно. Это не замена OB-EXT. В таблицу риска раздела про вход SCOB не подставляется.

**EQH / EQL.** Равные или очень близкие максимумы и минимумы, допуск 0.15 среднего диапазона. Там стоят чужие стопы. Цена часто снимает такой уровень перед разворотом. Сам уровень входом не является.

**PDH / PDL.** Максимум и минимум вчерашнего дня. Show history показывает несколько предыдущих дней. Разделитель дня — вертикальная пунктирная линия на смене даты.

**High Wick.** Свеча с длинной тенью. Порог по умолчанию 0.4: тень должна занимать хотя бы 40% всей свечи. Допустимый диапазон порога 0.3–0.5. Ниже порог — больше свечей и больше ложных отметок. Галочка Use close condition оставляет для покупки только бычьи свечи с нижней тенью, для продажи — только медвежьи с верхней. Верхняя тень подсвечивается цветом Large upper shadow, нижняя — Large lower shadow.

**Order Flow.** Пачка подряд идущих свечей одного направления с крупным телом. Бычья зона — где агрессивно покупали, медвежья — где продавали. Это область интереса, не сигнал на кнопку.

**IC и ICM.** IC — уровень открытия свечи, с которой начался последний импульс. ICM — середина этого импульса, «правильный откат». Тип `in` смотрит короткий импульс, `ex` — более крупный. Пока цена не дошла до ICM, откат может быть недобран.

**Сессии.** Четыре окна по времени брокера.

- A: 08:00–12:00
- B: 12:00–13:00
- C: 17:30–19:00
- D: 21:00–06:00, через полночь

У каждой есть сдвиг «Shift at broker time» в часах. Бокс — диапазон цены за это окно. Отдельно можно показать максимум и минимум, линию от открытия сессии к закрытию, среднюю цену и VWAP. Сессия объясняет, в какое время уровень появился, но не заменяет блок и свечу.

## Чего не делать

- Не входить по одной только зелёной, красной, голубой или фиолетовой свече.
- Не входить по блоку, пока в нём не закрылась свеча того же направления.
- Не считать пунктир Live BoS или Live ChoCh готовым сигналом.
- Не торговать SMT как обычный OB-EXT.
- Не увеличивать риск после убытка и не делать третий заход в ту же зону.
- Не ставить тейк «куда дойдёт». Дистанция тейка равна дистанции стопа.
- Не включать сразу все галочки Tools. График станет нечитаемым, и правила входа размажутся.
- Не путать 100% в таблице с риском на весь депозит.

## Оповещения

В SMC внешние оповещения по умолчанию включены. Для обычной работы выключите блок Alerts | External Structure. Внутренние (I-BoS и остальные) по умолчанию выключены.

В Tools оповещения выключены. Если включите, частота такая:

- Once per bar — не чаще одного раза за свечу, в том числе по ещё открытой;
- Once per candle close — только по уже закрытой свече.

Сообщение приходит окном Alert терминала. На телефон индикатор сам ничего не отправляет.

## Ограничения

Индикаторы не открывают ордера, не считают лот и не двигают стоп. Магического числа и проскальзывания у них нет, потому что заявок они не отправляют.

Часть числовых порогов в исходном описании не была задана: длина свинга, точные условия сигнальной свечи, допуск равных экстремумов, формула кривой ICM. В коде выбраны явные значения, они перечислены в этом файле и в комментариях в конце `.mq5`. Это рабочая реализация правил, а не обещание повторить чужой закрытый индикатор бар в бар.

Перед реальными деньгами посмотрите разметку на истории: найдите блоки, свечи и стопы по правилам выше и посчитайте, совпадает ли картинка с тем, как вы вообще хотите торговать.

## Итог: какая комбинация — какая сделка

Стрелка на графике — не заявка. 100% — обычный риск одной сделки, не весь депозит. Точки внизу подписаны: бирюзовые «покупка», красные «продажа».

Нет сделки:

- точки «продажа» или медвежий ChoCh, а свеча зелёная или голубая
- точки «покупка» или бычий ChoCh, а свеча красная или фиолетовая
- свеча есть, блока нет
- блок есть, свеча своего цвета не закрылась
- на зоне написано SMT или Previous OB-EXT
- стрелки нет

Покупка, свеча закрылась в бычьем блоке:

- зелёная + бычий OB-EXT = 100%
- зелёная + бычий OB-IDM = 50%
- голубая + бычий OB-EXT = 50%
- голубая + бычий OB-IDM = 25%

Продажа, свеча закрылась в медвежьем блоке:

- красная + медвежий OB-EXT = 100%
- красная + медвежий OB-IDM = 50%
- фиолетовая + медвежий OB-EXT = 50%
- фиолетовая + медвежий OB-IDM = 25%

Сразу со входом: стоп за блок, либо за большую свечу, либо за экстремум после теста. Тейк 1:1 равен стопу. Дальний тейк — следующий свинг, не дальше пяти стопов, иначе 2:1. Стоп и тейк не двигать, к убытку не добавлять.

После стопа один повтор в ту же зону: свип и новая свеча, риск снова по таблице. Второй стоп — кейс закрыт.
